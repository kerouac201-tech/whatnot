# 拾账 · Whatnot 经营账本

第一版中文收支管理程序。收入以美元为主，支出以人民币为主；原币分开统计，美元按逐笔确认的历史汇率折算人民币。

需求基线见 [需求分析 V1](docs/需求分析-v1.md)。

## 运行

需要 Node.js 22.13+（推荐当前环境的 Node 24）。使用 Node 内置 SQLite，数据库默认在 `data/ledger.sqlite`，不会上传到第三方。

```bash
cd /workspace/whatnot
npm ci --cache /tmp/whatnot-npm-cache
npm run dev
```

默认监听 `127.0.0.1:3000`。浏览器在运行机器上打开该地址。受控网络需要自设 `HOST` 和 `PORT`；没有认证，不要直接开放公网。

```bash
npm test
npm run build
npm start
```

`npm start` 服务生产构建；开发和生产共用数据库。`DB_PATH` 可指定独立数据库路径，自动创建目录。运行进程需要在后续任务中重启，安装文件和数据库保留。

## 首次使用

1. 在「账户与设置」确认默认美元汇率（初始 7.20 是手动估算值，非实时价格）与公司时区（初始美国太平洋时间）。
2. 新增真实账户并录入期初余额。初始账户余额均为零，可以暂不用预置账户。
3. 使用「记一笔」登记收入、支出；美元流水逐笔确认汇率。说明关键词会提供分类建议，冲突时待分类。
4. 备用金拨付使用同币种内部转账；员工垫付在支出中选择「员工个人垫付」，还款使用对应流水的「偿还」。
5. 主播工资通过录入工时和时薪计算；确认支付后自动生成工资流水。
6. 在流水页导出当前筛选结果；导入使用八列 CSV 模板，模板含示例，应替换为真实记录。导入失败不会部分写入。
7. 定期从设置页下载完整数据库备份，安全保存。备份通过 SQLite 一致性快照生成。

## 备份恢复

停止本程序；保留现有 `data` 目录的备份；将下载的备份放到一个新目录，例如 `/workspace/whatnot-restored/ledger.sqlite`，然后指定 `DB_PATH=/workspace/whatnot-restored/ledger.sqlite npm start`。不要覆盖运行中的数据库，不能混用原数据库的 WAL/SHM 文件。测试已验证快照能重新打开且流水数量一致。

## 已实现与边界

- 快捷录入、规则自动分类、搜索筛选、普通流水修改删除及审计日志。
- CNY/USD 账户与原币汇总、历史汇率人民币折算、分类图和六个月趋势。
- 同币种备用金转账、员工垫付及一次性偿还、兼职主播工时和防重复发薪。
- CSV 预览导入／筛选导出、SQLite 持久化、手动一致性备份。
- 当前为本地单人经营台账，无登录、审批、附件、平台同步、月度关账、库存成本、税务和自动异地备份。
- Whatnot 收入目前记实际到账；销售总额、平台费和退款对账需后续平台账单模块。
- 折算收支差额不是会计利润；老板注资／提款和内部资金往来不计经营收支。
- 已支付工资和已偿还垫付锁定，后续增加受控撤销／冲正；跨币种兑换未实现。

## 验证

`npm test` 为隔离数据库 API 测试；`npm run build` 为生产构建。浏览器流程测试使用系统 Chromium：

```bash
npx playwright test
```

浏览器测试使用单独临时数据库，不写入实际经营账本。每次新任务使用现有检出目录，不需要创建 Git worktree。
